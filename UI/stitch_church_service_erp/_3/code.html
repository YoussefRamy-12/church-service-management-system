ميثاق الاعتمادية والمزامنة

وثيقة سلامة البيانات والتشغيل دون اتصال (Offline-First)

save الحفظ المحلي أولاً

تُحفظ كافة بصمات الحضور وسجلات الافتقاد لحظياً في قاعدة بيانات المتصفح الآمنة (IndexedDB). يمكنك تسجيل الحضور كاملاً حتى وإن انقطعت شبكة الإنترنت بالقاعة دون فقد أي بيانات.

sync المزامنة الهادئة عند الاتصال

بمجرد التقاط شبكة واي فاي الكنيسة أو باقة الهاتف، يقوم النظام برفع الطوابع الزمنية للسحابة بترتيبها الزمني الأصلي مع حل أي تعارض تلقائياً دون تكرار أو مساس بسجلات الخدمة.

history_edu أمان السجلات التاريخية

في حال ترحيل تلميذ من فصل لآخر أو انتقال خادم، تظل كافة سجلات الحضور القديمة مرتبطة بالفصل والسنة الأصلية التي سُجلت فيها ضماناً لعدم تشويه أرشيف النمو الروحي.

check_circle تم اعتماد وحفظ إعدادات الخدمة ومزامنتها محلياً وسحابياً بنجاح.
